# DMX MIDI Converter Web UI prototype
React + TypeScript + Vite interface preview with simulated DMX values.

## Run
```bash
npm install
npm run dev
```

Prototype: dashboard, 512-channel monitor (banked 32 at a time), simulated stream, channel slider, mapping CRUD/edit/toggle, Wi-Fi mode preview, settings. State is in-memory only; no firmware/API integration yet.
